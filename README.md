# LLM Learning Daily

A repository for learning and experimenting with large language model (LLM) training and inference.

## About

This project is intended to document daily progress, notebooks, experiments, and examples for working with LLMs.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/poojagpta/LLM_learning_daily.git
cd LLM_learning_daily
```

## Contents

- Colab notebooks for LLM training
- Colab notebooks for LLM inference
- Additional experiments and learning resources
